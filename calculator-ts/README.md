# Scientific Calculator (TypeScript)

A strictly typed, minimalist, and high-precision scientific calculator built with TypeScript, modern CSS, and Vite.

---

## Features

- **Strict Type Safety**: Fully typed with custom TypeScript interfaces and types for operators, angle modes, actions, DOM elements, and history items.
- **Dual Modes**: Standard Mode & Scientific Mode (Trigonometry, Logarithms, Powers, Roots, Factorial, DEG/RAD, Constants π & e).
- **History & Memory**: LocalStorage persistent calculation history and standard memory operations (`MC`, `MR`, `M+`, `M−`, `MS`).
- **Tactile Audio Feedback**: Native Web Audio API synthetic click sounds.
- **Clipboard Integration**: One-click copying and clipboard paste (`Ctrl + V` / `Cmd + V`).
- **Modern Development**: Instant HMR dev server powered by Vite.

---

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
